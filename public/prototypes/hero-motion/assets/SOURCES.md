# Sense prototype assets

All assets are served locally and scoped to this prototype.

## JetBrains Mono

- Official specimen: https://www.jetbrains.com/lp/mono/
- Font: https://raw.githubusercontent.com/JetBrains/JetBrainsMono/v2.304/fonts/webfonts/JetBrainsMono-Regular.woff2
- Retrieved 2026-10-12; version v2.304, regular weight.
- License: SIL Open Font License 1.1; original copy in `JetBrainsMono-OFL.txt`.
- Used for the terminal text and window title.

## Surface grain

`surface-grain.svg` is an original 128px tiled procedural grayscale texture created for this prototype. Its static SVG filter supplies fine grain; it is not animated. No external artwork is embedded.

The previous Lucide decorations, Simple Icons strip and sample code field have been removed from Sense.

## Form sculpture

`folded-form.png` is original AI-generated artwork created with the built-in image generation tool on 2026-10-12. The full prompt and provenance are in `src/app/prototypes/hero-motion/ART-DIRECTION.md`. The source PNG is unchanged.
