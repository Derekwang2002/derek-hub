# Derek Hub · 首页艺术方向探索

本地原型，未集成或部署。范围是首页首屏与内容入口。沿用现有个人信息、项目与中英文路由；文案和视觉仍是提案。

预览：`http://localhost:3000/prototypes/art-direction/index.html`（使用现有 Next 开发服务）。

底部选择器、数字键 1–3 和左右方向键可切换；R / ↻ 重播短入场动画。`?v=1&lang=zh` 保存方案与语言。方案切换立即生效，不播放页面过渡。

| 方向 | 探索轴 | 后续全站延展 | 取舍 |
| --- | --- | --- | --- |
| Editorial / 刊物 | 字号对比、非对称排版、线条艺术 | 文章使用刊物式标题与边注；项目使用编号目录；资源保留紧凑索引 | 内容可读性与辨识度兼顾，但首屏更长 |
| Gallery / 展厅 | 空间感、深绿展厅、单件主视觉、可切换展签 | 项目首页如展览，详情以结构图和长文展开；阅读页应减少装饰 | 首页记忆点强，但同时可见的内容较少 |
| Notebook / 手稿 | 纸张层次、个人边注、工程草图 | 笔记增加边注与图解；项目展示思考过程；文章使用书页排版 | 个人气质鲜明，需限制倾斜和叠层，维护阅读秩序 |

三套方案都有中英文、响应式布局、键盘焦点和减少动态效果支持。细线图形为本地 SVG，不依赖外部字体、图片或新增 npm 包。展厅的 01 / 02 切换 CALL-E 与 MATRIX，并同步真实项目链接。

文件组织：每个方案一个 JS 模块；`shared.js` 提供共同导航与图形；`styles.css` 隔离原型视觉；`harness.js` 管理选择器。正式组件不引用这些文件。选择方向后再集成，并按需清理原型。

验证：已浏览三种桌面及手机布局，检查中英文内容及路由、项目切换、数字键/方向键、重播、刷新保留选择、控制台与模块语法。未修改正式组件，未运行全站生产构建。
